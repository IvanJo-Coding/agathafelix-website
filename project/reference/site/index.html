Berapa minimum order untuk produk custom?
+
Untuk produk tanpa cetak bisa pesan satuan. Untuk custom dengan cetak logo, MOQ mulai 100 pcs. Untuk rapor sekolah bisa mulai 30–40 pcs (1 kelas).
Bisakah pesan rapor sekolah dalam jumlah kecil?
+
Bisa! Kami melayani dari skala 1 kelas (~30–40 pcs) hingga seluruh sekolah. Semakin banyak, semakin hemat per satuannya.
Berapa lama waktu produksi order custom?
+
Umumnya 5–14 hari kerja setelah desain disetujui. Untuk kebutuhan mendesak tersedia jalur ekspres.
Apakah melayani pengiriman ke seluruh Indonesia?
+
Ya! Kami kirim ke seluruh Indonesia via ekspedisi rekanan. Untuk order besar ada kemungkinan gratis ongkir.
Bagaimana cara mengirim desain untuk cetak?
+
Kirim file logo/desain via WhatsApp (PNG, JPG, PDF resolusi tinggi). Tim kami bantu proses dan kirimkan preview digital sebelum produksi.
