Key things to know up front:
- Identity: playful "sticker sheet on warm paper" — cream background `#FFF8EE`, five logo colors (orange `#E8542D` primary, green, yellow, purple, sky blue), 2px ink outlines with flat offset shadows, pill buttons with a candy edge (`box-shadow: 0 4px 0 <deep color>`).
- Type: Baloo 2 (display, 800) + Plus Jakarta Sans (body) — Google Fonts substitutes; see readme Caveats.
- Copy: Bahasa Indonesia, "Anda"/"kami", factory-direct claims ("Langsung dari Pabrik — Bukan Reseller"), WhatsApp-first CTAs.
- WhatsApp green `#25D366` is reserved exclusively for conversion CTAs.
