# UI Kit — Marketing Website

Playful re-skin of the Agatha Felix marketing site (source: https://github.com/IvanJo-Coding/agathafelix-website — originally a dark industrial theme; the owner requested a colorful, education-friendly direction, so this kit keeps the source's page structure, sections, and copy but applies the new "sticker sheet" identity).

- `index.html` — interactive homepage (sticky nav, hero, two-path chooser, product grid, school section, 3 steps, testimonials, FAQ accordion, CTA band, footer, floating WA bubble).
- `Header.jsx` — sticky blurred nav + floating WhatsApp bubble + footer.
- `Sections.jsx` — hero, path cards, products, school highlight, steps, testimonials, FAQ, CTA band.

All visuals come from `../../styles.css` tokens and the compiled component bundle (`Button`, `Badge`, `Chip`, `SectionHeader`, `Stat`, `Step`, `FAQItem`, `TestimonialCard`, `ProductCard`). Copy is real site copy (Bahasa Indonesia, WhatsApp-first CTAs). Prices remain `Rp [TBD]` as in the source.
