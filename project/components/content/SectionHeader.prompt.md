Section intro block: eyebrow badge + Baloo 2 heading with one optional brand-colored word + short description.

```jsx
<SectionHeader
  eyebrow="Produk Kami"
  eyebrowColor="blue"
  title="Empat Produk Utama"
  highlight="Empat"
  highlightColor="orange"
  description="Semua diproduksi in-house dengan kontrol kualitas langsung."
/>
```

`align="left"` for asymmetric sections. Cycle eyebrow colors in rainbow order down a page.
