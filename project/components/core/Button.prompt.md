Pill CTA button with the brand's flat "candy edge" shadow that collapses on press; use color="wa" for every WhatsApp conversion CTA, "orange" for other primary actions, variant="ghost" for secondary.

```jsx
<Button color="wa" size="lg">Minta Penawaran Gratis</Button>
<Button variant="ghost">Lihat Produk ↓</Button>
```

Variants: solid (default) / ghost. Colors: orange (primary), wa (WhatsApp only), green, purple, blue. Sizes sm/md/lg. Pass `href` to render an anchor.
